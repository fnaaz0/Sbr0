# SBR Super-App — Multi-AI Production Engine 🧠✨

Welcome to the official repository of **SBR Super-App**, a highly secure, modern, dark-themed Progressive Web App (PWA) built strictly with a centralized multi-AI architecture.

## 🌟 Key Features & AI Integrations

*   **SBR Aql (OpenAI GPT-4o)**: Deep academic and contextual Islamic knowledge assistant targeting Quran, Tafsir, and Fiqh research modules.
*   **SBR Qalam (Anthropic Claude 3.5 Sonnet)**: Advanced text refinement, smart polishing, and creative outline generations for Notes and Dua Journals.
*   **SBR Safar (Google Gemini 2.5)**: Dynamic location intelligence assisting users as a reliable Masjid Locator and global travel helper.
*   **SBR Calligraphy (Image Gen API)**: Instant conversion of descriptive prompt phrases into high-resolution custom Arabic/Islamic calligraphy artwork.

## 🛡️ Centralized Production Architecture

This project strictly adheres to enterprise-grade security standards. No API keys are leaked or exposed to the client-side files (`index.html`). 
*   **Core Controller**: Managed centrally via `js/sbr-ai-core.js` to serve dynamic loading feedback ("Thinking... 🧠") and handle raw prompt payloads efficiently.
*   **Secure Routing**: Protected securely on the server-side environment under the encrypted serverless configurations schema (`api/sbr-ai-router.js`).
